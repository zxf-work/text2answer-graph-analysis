How a session works

Ask a first question, then follow up in plain words: which region are they from, show the top 20 instead, and within Bratislava. Each follow-up is planned against the session so far.

  • Reused: a step whose operator, parameters and inputs are identical to one already computed, traced back to the same graph under the same reading. Its stored result is used.
  • Executed: everything else. A result computed on a different scope or under a different reading is never reused.
  • Two contracts: when a request can be read two ways that give different answers, both are shown with what each would reuse, before anything runs.
