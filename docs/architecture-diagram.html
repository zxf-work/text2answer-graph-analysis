text2answer graph analysis: solution architecture

What happens between a question typed in plain words and a verified result, which component does each step, and where the language model sits. The model never sees the graph: it sees a profile card, writes a typed plan, and the system executes and checks it.

The same flow as steps

  1. Read the file. Chunked numpy path above 60 MB; row statistics, header roles, reciprocity, weight shape. t2r/graphs.py: read_raw, read_raw_fast
  2. Infer semantics. Directed, weighted and what the weights mean, multigraph, labelled; each with evidence and a confidence; weak evidence becomes a question to ask. infer_semantics
  3. Build the graph and the card. igraph graph kept in a process cache; the card holds cheap statistics plus the inferred semantics. load_graph, profile_card
  4. Plan (model call 1). Interpretation (what the question means on this file), optional clarification, a dataflow of catalogue operators, which step holds the answer. t2r/systems.py: PLANNER_SYSTEM; t2r/ir.py: Plan
  5. Validate. Every reference resolves, every argument has the right type, preconditions such as directed-only hold, node names resolve; one repair round if not. ir.validate
  6. Tier by cost. Estimate work per step; switch expensive steps to approximate tiers and shrink sample sizes until the budget holds. ir.estimate_cost, auto_tier
  7. Execute. Steps run in order on igraph; intermediate values are typed and cached; a trace records time and a summary per step. ir.execute; t2r/ops.py
  8. Verify. Invariants (partition covers the graph, PageRank sums to one, path is a walk), agreement between measures, and consistency between question, interpretation and plan; an error sends the plan back once. t2r/verify.py
  9. Extract and explain (model call 2). The answer step(s) become the answer; other rankings become variants; the explainer writes prose from trace and findings. ir.extract_answer; INTERPRETER_SYSTEM
  10. Present. Answer, interpretation, findings, cost and a sampled neighbourhood with the answer nodes marked. demo/server.py, demo/viz.py, demo/static/
